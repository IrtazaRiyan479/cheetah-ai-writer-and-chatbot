Overview & stack

AffiGenie is an AI writing and affiliate-publishing application, with image generation, WordPress publishing, Stripe billing, and a private operator console.

DONE · Source-confirmed
ApplicationNext.js App Router; localized private routes under src/app/[lang].
UIJavaScript/JSX, MUI, and Vuexy layout conventions.
DataPrisma ORM. The checked datasource provider is MySQL.
IdentityNextAuth credentials and Google providers; user roles are reloaded from Prisma.
Typical flow: sign in → select article type → generate outline → generate sections → review/edit → save a draft or publish.

Authentication & admin unlock

Credentials and Google sign-in are configured through NextAuth. Password changes verify the current password.

GATE · Identity required

Password change: POST /api/user/password, current password required, new password at least eight characters.

Two locks for the admin console

  1. Signed-in user’s database role must equal admin.
  2. Operator key is submitted to POST /api/admin/unlock; successful unlock sets an HTTP-only, Secure, SameSite Strict cookie for approximately eight hours.

POST /api/admin/lock clears the cookie. Failed unlock attempts have process-local backoff. Never store or log the key.

Generation pipeline & shared helpers

The writer requests an outline, then article sections. Individual services may fetch product, search, or media data.

DONE · Shared path

Provider sequence

1 · xAI / Grok2 · Mistral3 · Groq4 · Gemini

Gemini keys are read in order from GEMINI_API_KEYS, numbered key variables, then legacy key variables. Quota/rate-limit/503 responses rotate to the next key. Provider order is code-controlled.

Shared helpers

  • Check Price: English label is exactly Check Price on Amazon.; affiliate URL and ASIN handling are shared.
  • Responsive tables: renderResponsiveTable outputs .affigenie-table with mobile-card CSS.
  • Top Pick: renderTopPickCards is used for the roundup card layout.
  • Branded hero: shared helper chooses a relevant photo or branded gradient fallback.
  • Error handling: serializeError produces bounded readable text, avoiding [object Object].

Images

Stock imagery is filtered for relevance; branded heroes use an image when suitable or a gradient fallback.

GATE · User history

Optional stock providers: Pexels, Pixabay, Unsplash. Standalone image generation is an SSE flow with Preparing → Generating → Done/Error stages.

  • GET /api/generate-image requires a session and returns only that user’s image history.
  • POST /api/generate-image uses the image-standalone entitlement.
  • DELETE /api/generate-image requires a DB admin and removes image records globally.
  • TinyPNG compression is attempted when lossless mode is off; compression failure retains the original.
DONE · Empty history is valid; demo gallery data is not seeded

WordPress publishing

POST /api/publish checks the wp-publish entitlement and returns serialized WordPress/network errors.

GATE · Entitlement

When a featured image is uploaded, its media ID is assigned to WordPress featured_media. The hero is also retained in article content where applicable.

Test safely. Use a staging/demo WordPress site. Verify the featured media and in-content hero before an approved production publish.
